গুগল শিট কানেকশন ইতিমধ্যে কনফিগার করা হয়েছে। এটি পরিবর্তন বা দেখতে হলে দয়া করে অ্যাডমিন পাসওয়ার্ড প্রদান করুন।

🚀 ৫ মিনিটে গুগল শিট কানেক্ট করার সহজ গাইড

নিচের ৪টি সহজ ধাপ অনুসরণ করে আপনার ফ্রি গুগল স্প্রেডশিটটিকে একটি ফুল রিয়েল-টাইম ক্লাউড ডেটাবেস হিসেবে ব্যবহার করুন। কোনো ডাটাবেস হোস্টিং বা সার্ভার ফি দিতে হবে না!

১ একটি নতুন গুগল শিট তৈরি করুন

আপনার গুগল ড্রাইভে গিয়ে একটি নতুন ব্ল্যাংক স্প্রেডশিট খুলুন। ফাইলের নাম দিন যেমন: Life Free Pro Database।

২ Apps Script কোডটি পেস্ট করুন

গুগল শিটের মেনুবার থেকে Extensions (এক্সটেনশন) ➔ Apps Script (অ্যাপস স্ক্রিপ্ট) এ ক্লিক করুন। সেখানে থাকা কোড মুছে দিয়ে নিচের সম্পূর্ণ কোডটি কপি করে পেস্ট করুন এবং Save (সংরক্ষণ) করুন।

৩ Web App হিসেবে Deploy করুন

Apps Script এডিটরটির ওপরের ডানদিকের নীল বাটন Deploy ➔ New deployment এ ক্লিক করুন:

  • Select type (গিয়ার আইকন): Web app সিলেক্ট করুন।
  • Description: LFP Reporting লিখুন।
  • Execute as: Me (আপনার জিমেইল) রাখুন।
  • Who has access: অবশ্যই Anyone সিলেক্ট করুন (যাতে আপনার কর্মীরা শিটে রিপোর্ট সাবমিট করতে পারে)।
  • Deploy বাটনে ক্লিক করে পারমিশন এক্সেস দিন (Review permissions ➔ Advanced ➔ Go to ... Unsafe ➔ Allow)।
  • অবশেষে প্রাপ্ত Web app URL টি কপি করুন (যা দেখতে হবে https://script.google.com/macros/s/.../exec)।

৬ অ্যাডমিন প্রোফাইল ও নিরাপত্তা নির্ধারণ করুন

অ্যাডমিন হিসেবে লগইন করার জন্য আপনার পাসওয়ার্ড ও তথ্য সেট করুন। এই পাসওয়ার্ডটি গুগল শিটের Users ট্যাবে লিপিবদ্ধ থাকবে।
